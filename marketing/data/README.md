# Source data

Download Marketing A/B Testing from https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing and extract marketing_AB.csv into this directory. Retain the original field names and Boolean values. Review the original publisher's dataset terms on Kaggle.

The raw CSV, cleaned user-level CSV and local SQLite database are intentionally not included in the public GitHub repository. They are available in the local complete project bundle. The Power BI report uses a disjoint aggregate cube (2,196 cells); it contains no user IDs.
